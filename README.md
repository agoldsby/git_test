## AI Tutorial: Basics

An interactive course that runs inside Claude or ChatGPT. The AI is the instructor.

- **To take or share the course:** download `dist/ai-tutorial-basics.zip` (or the `ai-tutorial-basics/` folder) and follow `START-HERE.txt`. In short: drag `COURSE.md` into a new chat and type **start**.
- **To edit the course:** see [`authoring/README.md`](authoring/README.md).
