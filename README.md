## AI Agent Basics

An interactive course that teaches people how to work with AI agents. It runs inside Claude or ChatGPT, and the AI is the instructor.

- **To take or share the course:** download `dist/ai-agent-basics.zip`, unzip it, open the folder in the Claude or ChatGPT desktop app (ChatGPT: Work mode), and type **start**. Or upload the zip to any chat and type **start**.
- **To edit or deliver the course:** see [`authoring/README.md`](authoring/README.md).
