STYLE GUIDE: Full Project Document
Use for: the shared project doc where the full detail lives

Structure (use these headings in this order):
1. Summary (3-4 sentences)
2. Background & Data
3. What We Heard (themes, with which stakeholders raised them)
4. Areas of Agreement
5. Open Tensions & Trade-offs
6. Recommendation
7. Next Steps (table: Action | Owner | Due date)

Rules:
- Thorough but scannable: short paragraphs, bullets, tables.
- Neutral tone. Represent every stakeholder's view fairly.
- Link claims to evidence (who said it, or which number).
