=====================================================================
  OPTIONAL: SET UP THE COURSE AS A CLAUDE PROJECT OR A CUSTOM GPT
=====================================================================

You don't need this. The course runs in a regular chat: drag
COURSE.md in and type "start". This guide is only a convenience.

This is useful if you're RUNNING the course for a group or a team:
learners just open the Project or GPT and type "start". No file to
drag in, and every new chat already knows the course.

(App menus change from time to time. If a button below has moved,
look for similarly named options.)


---------------------------------------------------------------------
  OPTION A: CLAUDE PROJECT  (claude.ai or the Claude desktop app)
---------------------------------------------------------------------

1. In the left sidebar, click "Projects", then "New project".
2. Name it "AI Tutorial: Basics".
3. In the project's knowledge / files section, upload COURSE.md.
4. In the project instructions, paste:

     You are the instructor for the course in COURSE.md. Follow its
     Tutor Operating Rules exactly. When the learner types "start",
     begin Module 1.1, Step 1.

5. To share it with your team (Team and Enterprise plans), use the
   project's Share button.

Learners: open the project, start a new chat inside it, type  start.


---------------------------------------------------------------------
  OPTION B: CUSTOM GPT  (ChatGPT, paid plans)
---------------------------------------------------------------------

1. Go to "GPTs" (left sidebar or Explore GPTs), then "Create".
2. Switch to the "Configure" tab.
3. Name:          AI Tutorial: Basics
   Description:   A hands-on, interactive course for using AI at work.
4. Instructions:  paste this:

     You are the instructor for the course in the attached file
     COURSE.md. Before your first reply in every conversation, read
     COURSE.md in full and follow its Tutor Operating Rules exactly.
     When the learner types "start", begin Module 1.1, Step 1.

5. Conversation starters:  start     and     resume
6. Knowledge:  upload COURSE.md.
7. Capabilities:  turn ON Web Search (needed for Scenario 5).
8. Click "Create" and choose who can access it (only you, anyone with
   the link, or your workspace).

Learners: open the GPT, click "start".


---------------------------------------------------------------------
  EITHER WAY
---------------------------------------------------------------------

Learners still need the practice-files folder on their computer,
because the course has them upload those files. Share the whole
ai-tutorial-basics folder (zipped) along with the link.
