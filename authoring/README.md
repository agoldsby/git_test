# Authoring & delivery guide: AI Agent Basics

This folder is for people who **maintain or deliver** the course. Learners never see it.
They get only `dist/ai-agent-basics.zip`.

## How the course works

There are two ways to open the course. Both run the full course.

| | **Folder mode** (recommended) | **Zip mode** (fallback) |
|---|---|---|
| Learner does | Unzips the folder, opens it in the Claude or ChatGPT **desktop app** (ChatGPT: **Work** mode), types **start** | Drags `ai-agent-basics.zip` into any Claude or ChatGPT chat, types **start** |
| Where files change | On the learner's own computer. They watch their files change in File Explorer / Finder. | In the AI's private workspace. The learner gets downloads. |
| Good for | The full "agent edits my files" experience | Browser users, or anyone stuck on setup |

The AI works out which mode it's in (see `AGENTS.md`, section 1). Module scripts mark the
lines that differ with **[folder]** and **[zip]**, and `📂 [see the file]` marks the
spot where the learner checks a result: open it in their folder, or download it.

Progress lives in the conversation, so learners come back by reopening the chat from the
app's sidebar.

```
ai-agent-basics/
├── README.md                 ← for humans: the 3 launch steps
├── AGENTS.md                 ← course runner: the AI reads this first
├── CLAUDE.md                 ← identical copy (generated by build.py)
├── company-context/          ← Relay background (COMPANY, PRODUCT, PERSONAS, COMPETITIVE)
└── lesson-modules/
    ├── module-1.1-welcome/
    │   └── MODULE.md         ← Module 1.1 script
    └── module-1.2-first-tasks/
        ├── MODULE.md         ← Module 1.2 script + answer keys
        ├── meeting-notes-raw.md, product-sync-notes.md
        ├── stakeholder-feedback/   (8 responses)
        ├── communication-styles/   (3 style guides)
        └── dashboard-example.png
```

### What gets created during the course

| Scenario | The AI's action |
|---|---|
| 1 — Meeting notes | **Appends** an Action Item Summary to `meeting-notes-raw.md`, then saves the learner's own request on `product-sync-notes.md` |
| 2 — Feedback synthesis | **Creates** `stakeholder-feedback/feedback-synthesis.md` from all 8 files |
| 3 — Communications | **Creates** `communication-styles/research-communications.md` from the synthesis + style guides |
| 4 — Dashboard | **Creates** `dashboard-talking-points.md` from the image |
| 5 — Web research | **Creates** `onboarding-research.md` with source links |
| Wrap-up | Folder mode: points the learner to their folder. Zip mode: **zips** everything into `my-relay-work.zip` to download. |

## Delivering the course to learners

LinkedIn posts can't attach a zip, so host `ai-agent-basics.zip` somewhere with a public
download link (a public GitHub repo, Google Drive, Dropbox, or a landing page) and link to
it from the post. Put the launch steps both in the post and on the download page:

> 1. Download **ai-agent-basics.zip** and unzip it (Windows: right-click → Extract All; Mac: double-click).
> 2. Open the **Claude** or **ChatGPT** desktop app and start a chat that can use a folder on your computer (in ChatGPT, switch to **Work** mode). Add the **ai-agent-basics** folder.
> 3. Type **start**.
>
> Using a browser, or can't add a folder? Drag the zip into any Claude or ChatGPT chat and type **start**. It works there too.

The same steps are in `README.md` inside the folder, for people who unzip first.

**Things to know:**
- **ChatGPT has separate Chat and Work modes.** The course needs Work mode, which can open a
  local folder. Plain Chat mode will ask the learner to switch.
- **Claude** can open a local folder in the desktop app. In a browser, the zip upload works
  as long as *Code execution and file creation* is on (Settings → Capabilities); it's on
  by default for most accounts.
- **Permission prompts (folder mode):** the app may ask before the AI edits a file. The
  course warns learners before the first edit and tells them to click **Allow**.
- **Web search** (Scenario 5) may be off on some plans or work accounts. The course
  handles this and keeps going.
- **Folder-mode edits are permanent.** Learners who want a fresh start unzip the original
  download again.
- **Zip-mode workspaces can reset** if a chat sits idle for a long time. The AI asks the
  learner to upload the zip again and recreates their work.

## Editing the course

Edit the files in `ai-agent-basics/` directly:

| To change… | Edit |
|---|---|
| How the AI runs the course (rules, commands, app differences) | `ai-agent-basics/AGENTS.md` (never `CLAUDE.md`, which is generated) |
| Module 1.1 | `ai-agent-basics/lesson-modules/module-1.1-welcome/MODULE.md` |
| Module 1.2, including answer keys | `ai-agent-basics/lesson-modules/module-1.2-first-tasks/MODULE.md` |
| Relay background | `ai-agent-basics/company-context/*.md` |
| Practice files | `ai-agent-basics/lesson-modules/module-1.2-first-tasks/` (update the answer keys too!) |

Then rebuild from the repository root:

```bash
python3 authoring/build.py
```

The build copies `AGENTS.md` to `CLAUDE.md`, checks that every file the scripts mention
exists, refuses to ship files the AI is supposed to create, and writes
`dist/ai-agent-basics.zip`.

**Adding a module:** create `lesson-modules/module-1.3-<name>/MODULE.md`, add it to the
module table and course map in `AGENTS.md`, and point the last step of the previous module
at it.

### Script conventions

- **Say:** text the AI sends nearly word-for-word.
- **Check:** the AI stops and waits for the learner.
- **Action:** work the AI does with its tools (reading or writing files, searching).
- **Present it like this:** a template for showing a result, filled in from the real output.
- Put the exact phrase you want the learner to type in **bold**, and put requests they
  should copy in a `>` quote block.
- **Every scenario must end with a file changed or created.** That's what makes the course
  about agents, not chatbots.

## Testing checklist

Run through the course in **folder mode** and in **zip mode**, in both **Claude** and
**ChatGPT (Work mode)**, and check that:
- [ ] typing **start** begins Module 1.1 Step 1 (no "I've unzipped the files…")
- [ ] folder mode: the side-by-side File Explorer step appears, and edits show up in the learner's own files
- [ ] zip mode: the one-line "unzip for the full experience" tip appears once, and every result comes with a download
- [ ] the AI stops at every Check
- [ ] Scenario 1 actually appends to `meeting-notes-raw.md`, and the download shows it
- [ ] Scenarios 2–5 each create their file, and each file can be downloaded
- [ ] skipping straight to Scenario 3 still works (the AI creates the synthesis first)
- [ ] web search on and off are both handled
- [ ] folder mode: the wrap-up points to the folder; zip mode: the wrap-up zip contains everything
