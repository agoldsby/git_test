# Authoring & delivery guide: AI Agent Basics

This folder is for people who **maintain or deliver** the course. Learners never see it.
They get only `dist/ai-agent-basics.zip`.

## How the course works

1. The learner uploads **`ai-agent-basics.zip`** to a chat in Claude or ChatGPT and types **start**.
2. The AI unzips it in its own workspace and reads `AGENTS.md` (`CLAUDE.md` is an identical
   copy, so either app finds it).
3. The AI acts as the instructor, following each module's `MODULE.md` script, and does the
   work on real files: it appends to the meeting notes and creates the synthesis, the
   communications, the talking points, and the research report. Each one comes back to the
   learner as a download.
4. Progress lives in the conversation itself, so learners come back by reopening the chat
   from the app's sidebar.

```
ai-agent-basics/
├── AGENTS.md                 ← course runner: the AI reads this first
├── CLAUDE.md                 ← identical copy (generated by build.py)
├── company-context/          ← Relay background (COMPANY, PRODUCT, PERSONAS, COMPETITIVE)
└── lesson-modules/
    ├── module-1.1-welcome/
    │   └── MODULE.md         ← Module 1.1 script
    └── module-1.2-first-tasks/
        ├── MODULE.md         ← Module 1.2 script + answer keys
        ├── meeting-notes-raw.md, product-sync-notes.md
        ├── stakeholder-feedback/   (8 responses)
        ├── communication-styles/   (3 style guides)
        └── dashboard-example.png
```

### What gets created during the course

| Scenario | The AI's action |
|---|---|
| 1 — Meeting notes | **Appends** an Action Item Summary to `meeting-notes-raw.md`, then saves the learner's own request on `product-sync-notes.md` |
| 2 — Feedback synthesis | **Creates** `stakeholder-feedback/feedback-synthesis.md` from all 8 files |
| 3 — Communications | **Creates** `communication-styles/research-communications.md` from the synthesis + style guides |
| 4 — Dashboard | **Creates** `dashboard-talking-points.md` from the image |
| 5 — Web research | **Creates** `onboarding-research.md` with source links |
| Wrap-up | **Zips** everything into `my-relay-work.zip` for the learner to download |

## Delivering the course to learners

Send them the zip and a short note like this:

> **AI Agent Basics**: a hands-on, ~1–2 hour course that runs inside your AI app.
> 1. Download the attached **ai-agent-basics.zip**. Don't unzip it.
> 2. Open **Claude** or **ChatGPT** on your computer (desktop app or browser) and start a new chat.
> 3. Drag the zip file into the chat, type **start**, and press Enter.
>
> In ChatGPT, if it asks you to switch to **Work** mode, say yes. The course needs a mode
> that can work with files.

**Things to know:**
- **ChatGPT has separate Chat and Work modes.** Chat mode can't run the course and will ask
  the learner to switch. That's expected. Mention it up front so it isn't a surprise.
- **Claude** handles this in a regular chat, as long as *Code execution and file creation*
  is turned on (Settings → Capabilities). It's on by default for most accounts.
- **Web search** (Scenario 5) may be off on some plans or work accounts. The course
  handles this and keeps going.
- **Workspaces can reset** if a chat sits idle for a long time. If a learner comes back
  and the files are gone, the AI asks them to upload the zip again and recreates their work.

## Editing the course

Edit the files in `ai-agent-basics/` directly:

| To change… | Edit |
|---|---|
| How the AI runs the course (rules, commands, app differences) | `ai-agent-basics/AGENTS.md` (never `CLAUDE.md`, which is generated) |
| Module 1.1 | `ai-agent-basics/lesson-modules/module-1.1-welcome/MODULE.md` |
| Module 1.2, including answer keys | `ai-agent-basics/lesson-modules/module-1.2-first-tasks/MODULE.md` |
| Relay background | `ai-agent-basics/company-context/*.md` |
| Practice files | `ai-agent-basics/lesson-modules/module-1.2-first-tasks/` (update the answer keys too!) |

Then rebuild from the repository root:

```bash
python3 authoring/build.py
```

The build copies `AGENTS.md` to `CLAUDE.md`, checks that every file the scripts mention
exists, refuses to ship files the AI is supposed to create, and writes
`dist/ai-agent-basics.zip`.

**Adding a module:** create `lesson-modules/module-1.3-<name>/MODULE.md`, add it to the
module table and course map in `AGENTS.md`, and point the last step of the previous module
at it.

### Script conventions

- **Say:** text the AI sends nearly word-for-word.
- **Check:** the AI stops and waits for the learner.
- **Action:** work the AI does with its tools (reading or writing files, searching).
- **Present it like this:** a template for showing a result, filled in from the real output.
- Put the exact phrase you want the learner to type in **bold**, and put requests they
  should copy in a `>` quote block.
- **Every scenario must end with a file changed or created.** That's what makes the course
  about agents, not chatbots.

## Testing checklist

Run through the course once in **Claude** and once in **ChatGPT (Work mode)** and check
that:
- [ ] uploading the zip and typing **start** begins Module 1.1 Step 1 (no "I've unzipped the files…")
- [ ] the AI stops at every Check
- [ ] Scenario 1 actually appends to `meeting-notes-raw.md`, and the download shows it
- [ ] Scenarios 2–5 each create their file, and each file can be downloaded
- [ ] skipping straight to Scenario 3 still works (the AI creates the synthesis first)
- [ ] web search on and off are both handled
- [ ] the wrap-up zip contains everything
